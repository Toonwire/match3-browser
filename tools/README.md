# Tools

## Pop Sound Generator

`generate_pop_sound.html` - A simple web-based tool to generate pop sound effects.

### How to Use:

1. Open `generate_pop_sound.html` in your web browser
2. Adjust the sliders to customize the pop sound:
   - **Frequency**: Lower = deeper pop, Higher = sharper pop
   - **Duration**: How long the sound lasts
   - **Attack**: How quickly the sound starts
   - **Decay**: How quickly the sound fades out
   - **Volume**: Overall volume
   - **Noise**: Adds "bubbly" texture to the sound
3. Click "Play" to preview
4. Click "Download WAV" to save the sound
5. Convert to MP3 using:
   - Online converter (e.g., cloudconvert.com, zamzar.com)
   - Audacity (File → Export → Export as MP3)
6. Move the MP3 file to `assets/sounds/match_pop.mp3`

### Recommended Settings for Match Pop:

- **Frequency**: 150-250 Hz (deeper, more satisfying)
- **Duration**: 80-120 ms (quick and snappy)
- **Attack**: 3-8 ms (instant start)
- **Decay**: 40-80 ms (quick fade)
- **Volume**: 0.7-0.9
- **Noise**: 0.2-0.4 (subtle texture)

### Alternative: Quick Default Pop

Click "Reset to Default" and then "Download WAV" for a good starting point.
